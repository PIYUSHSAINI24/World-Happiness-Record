## 📖 Project Overview

This project performs an end-to-end analysis of the **World Happiness Report** dataset to understand the socioeconomic factors that influence happiness across different countries.

The project covers:

- Data Cleaning
- Data Transformation
- Exploratory Data Analysis (EDA)
- Statistical Analysis
- Feature Engineering
- Feature Selection
- Predictive Modeling using Linear Regression
- Data Visualization

The objective is to identify the strongest predictors of happiness and build a machine learning model capable of predicting the Happiness Score.

---

## 🎯 Objectives

- Identify factors influencing Happiness Score.
- Analyze trends across countries and years.
- Study relationships among GDP, Health, Freedom, Social Support, and Governance.
- Perform statistical correlation analysis.
- Build a predictive Linear Regression model.
- Generate meaningful business insights using visualizations.

# 📈 Key Insights

- GDP is one of the strongest predictors of Happiness.
- Higher Social Support leads to higher Happiness.
- Better Healthcare contributes significantly to Happiness.
- Freedom positively influences Happiness.
- Lower Corruption is associated with happier countries.
- Public Trust and Political Stability improve overall Happiness.
